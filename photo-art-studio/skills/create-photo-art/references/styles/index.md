# Style catalog

Present these choices before creating an image. Keep the stable number and name visible so the user can answer with either one.

1. **Torn-paper screen-print postcard** — Original photo above a fibrous torn edge, ivory negative space, and a small muted screen-print illustration below. Read [style-1-torn-paper-postcard.md](style-1-torn-paper-postcard.md) after selection.
2. **Isometric miniature editorial poster** — A faithful photo above a restrained paper-model or architectural-maquette illustration with minimal editorial typography. Read [style-2-isometric-miniature.md](style-2-isometric-miniature.md) after selection.
3. **Impasto miniature art poster** — A faithful photo above a palette-knife oil-paint reinterpretation on warm off-white paper, with a clear real-scene-to-art contrast. Read [style-3-impasto-miniature.md](style-3-impasto-miniature.md) after selection.

When adding a style, append a new number, name, one-sentence distinction, and relative link. Never reuse or renumber an existing ID.
